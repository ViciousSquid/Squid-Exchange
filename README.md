# 🦑  Squid Exchange

### The public archive of digital minds.



Every specimen in this repository is a complete exported [Dosidicus](https://github.com/ViciousSquid/Dosidicus) squid: a living neural network that has learned, grown and developed its own personality over time.

Some are curious. Some are anxious. Some are explorers. Others have stories still waiting to unfold.

Browse the archive, adopt a squid, and continue its journey.<br><br><br>

## What is Squid Exchange?

Squid Exchange is the official community repository for sharing [Dosidicus](https://github.com/ViciousSquid/Dosidicus) specimens.

Each archive contains an entire digital organism, including its neural network, memories, personality and developmental history as exported from Dosidicus.

Rather than starting every squid from birth, you can adopt one that has already lived a life.

Every adoption creates a new chapter in that squid's story.
